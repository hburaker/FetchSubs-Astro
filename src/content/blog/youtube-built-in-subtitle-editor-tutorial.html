YouTube Studio has its own subtitle editor, and for small fixes it's the quickest place to correct captions on your own videos: open Subtitles in the left menu, pick the video, and edit the track in the browser. For automatic captions you first make an editable copy with Duplicate and edit. For long transcripts with lots of errors, downloading the file, fixing it in a text editor and uploading it again is usually faster.

The steps below follow YouTube's own help pages, linked in each section, because Studio's layout changes now and then. If a button has moved, the help page is the place to check.

What auto-generated captions usually get wrong

It helps to know what you're looking for before you start editing. Here are the first lines of the auto-generated English track of Steve Jobs' 2005 Stanford commencement address, exported to SRT with FetchSubs:

2
00:00:07,520 --> 00:00:11,880
this program is brought to you by

3
00:00:08,960 --> 00:00:14,880
Stanford University please visit us at

...

5
00:00:20,519 --> 00:00:23,519
thank

6
00:00:26,080 --> 00:00:30,400
you I'm uh honored to be with you today

The recognition itself is good here; the words are right. The problems are typical, though. There is almost no punctuation, filler words like "uh" are kept, "thank you" is split across two captions several seconds apart, and the timings overlap (block 3 starts before block 2 ends). YouTube's help page on automatic captions says plainly that they "might misrepresent the spoken content" because of accents, dialects or background noise, and advises creators to review them (Use automatic captioning). In practice the things to check first are names, technical terms, numbers, and any sentence that spans several captions.

For a longer look at where auto captions go wrong, see how accurate YouTube's auto-generated subtitles are.

Opening the editor

According to YouTube Help (Edit or remove captions):

  1. Sign in to YouTube Studio.
  2. Select Subtitles from the left menu.
  3. Click the video you want to work on.
  4. Find the language in the Subtitles column and click Edit.

Automatic captions can't be edited in place. Choose Duplicate and edit, then Continue. YouTube creates a new caption track that includes your changes. The help page warns that continuing overwrites any draft you already have for that language, so if you've started edits earlier, finish or publish those first.

Fixing text and timing

Click into the caption text and type your correction. If you don't see timestamps next to the captions, click Edit timings to show them and adjust when each caption appears and disappears.

A few habits make this go faster:

  • Play the video and fix captions as they come up, rather than reading the text cold. Errors in names and jargon are much easier to hear than to spot.
  • When a sentence is split oddly, like "thank" / "you" above, move the stray word into the neighbouring caption rather than leaving a one-word caption on screen.
  • Keep each caption short enough to read comfortably. If you add punctuation and the line grows long, split it.

When you're done, click Publish to make the changes live. There is no reason to wait for a perfect pass; you can come back and edit the track again later.

Adding a new language

For a language the video doesn't have yet, YouTube Help (Add subtitles & captions) describes this route: on the video's Subtitles page click Add language, choose the language, then click Add under Subtitles. You then pick one of three methods:

  • Upload file, choosing With timing for a subtitle file such as SRT or VTT, or Without timing for a plain transcript.
  • Auto-sync: paste or upload a transcript and YouTube works out the timing, which can take a few minutes. The text has to be in the language spoken in the video, and the help page says it isn't recommended for videos over an hour or with poor audio.
  • Type manually: play the video and type captions as you go; the timings are set automatically. The help page lists a set of keyboard shortcuts for this mode, such as seeking back or forward a second, pausing, and moving between subtitles. Check the page for the exact keys rather than guessing.

For a translation, the upload route usually gives the best result: export the corrected track in the original language, translate it (by hand, with a translator, or with machine translation that a fluent speaker checks), and upload it With timing. Because the timings come along with the file, the translated captions line up with the video. The post on translating YouTube subtitles goes through that process.

When to edit outside Studio instead

The browser editor is fine for a handful of fixes. It gets slow when the same mistake appears forty times, say a guest's surname that the speech recognition never gets right. A text editor's find-and-replace fixes that everywhere in one go.

For that round trip you need the captions as a file. For your own videos, Studio can give it to you: Options, then Download subtitles. YouTube Help also mentions this as the way to change timing on automatic captions: download the file and upload it again. FetchSubs works too if you prefer it; paste the video link, pick the auto-generated or official track, and download SRT. Either way:

  1. Open the SRT in a plain text editor (not a word processor, which can add formatting).
  2. Fix names and terms with find-and-replace, then read through for punctuation and odd splits.
  3. Don't touch the numbered lines or the --> timing lines unless you mean to change the timing, and keep the blank line between blocks.
  4. Save as UTF-8 and upload it with Upload file > With timing.

If you want to nudge every caption earlier or later by the same amount, that's also easier on the file than in the browser. The post on fixing subtitle timing in SRT files covers how.

Which to use

Use Studio's editor when the auto captions are mostly right and you're fixing a few words, or when you want to check how the captions look over the video before publishing. Download and edit the file when there are many repeated errors, when you're translating, or when you want a copy of the corrected captions for other platforms. A clean SRT kept on your own disk is also a backup that doesn't depend on YouTube.
