Getting YouTube subtitles onto a Chromebook is easy: FetchSubs runs in Chrome like any other website, and the SRT, VTT or TXT file lands in the Downloads folder of the Files app. Using that file afterwards needs a little more thought than on Windows or macOS, where you'd simply open the video in a desktop player and point it at the subtitle file. This post covers both halves, plus Live Caption, which is sometimes the better answer.

Downloading the subtitles

  1. Copy the YouTube link from Chrome's address bar (or from the Share button under the video).
  2. Open fetchsubs.com in a new tab, paste the link into the box and press Download or Enter.
  3. A list of the video's caption tracks appears. Each row shows the language and whether it is (Official), meaning uploaded by the creator, or (Auto-generated) by YouTube's speech recognition.
  4. Click SRT, VTT or TXT on the row you want. Or click RAW to read the text in a new tab without saving anything.

Chrome saves the file to Downloads, which you'll find in the left-hand list of the Files app. The name is built from the video title and the language code, such as Me_at_the_zoo_en.srt, with _auto added for auto-generated tracks.

Which format? SRT if the captions are going onto a video, VTT if you're putting a video on a web page, TXT if you only need the words. The SRT vs VTT vs TXT post shows real samples of each.

If the Chromebook belongs to a school or an employer, the administrator decides which sites you can open and whether downloads are allowed. If the file won't save on a managed device, that is usually a policy setting rather than a problem with the file.

Watching a video with an SRT file

This is where Chromebooks differ from other laptops. Google's Chromebook Help doesn't describe a way to load a separate subtitle file into the built-in Gallery app, so I wouldn't plan around it. Two routes are documented and work on any Chromebook that can run them.

Option 1: Add the SRT as a caption track in Google Drive

Google Drive can attach caption files to videos you've uploaded, and on a Chromebook Drive is never far away. According to Google's help page on adding caption tracks to your video files, the steps on drive.google.com are:

  1. Upload the video to Drive if it isn't there already.
  2. Right-click the video, open File information and choose Manage caption tracks.
  3. Click Add new caption tracks, then Select file, and pick the SRT from Downloads.
  4. Set the language and a name for the track, then click Upload.

Drive accepts both SubRip (.srt) and WebVTT (.vtt). A few limits from the same page: the caption file has to be under 2 MB, SRT files have to be plain UTF-8, and the captions belong to that version of the video, so uploading a new version removes them. A subtitle file for even a long talk is normally far below 2 MB, because it is only text.

This only makes sense if the video file is actually yours or you have the right to keep a copy of it. If you're just watching something on YouTube, you don't need a file at all: the CC button in YouTube's player shows the same captions.

Option 2: An Android video player

Many Chromebooks can install Android apps from Google Play, but not all of them, and school or work devices may have it turned off (see Install & use Android apps on your Chromebook). If your device has the Play Store, you can install a video player that supports external subtitle files and open the video and the SRT from there. Support for separate subtitle files varies between apps and versions, so check the app's description before you rely on it, and keep the video and the SRT in the same folder with the same base name (lecture.mp4 and lecture.srt), which is the convention most players look for.

Live Caption: captions for things that don't have any

ChromeOS has its own captioning feature, Live Caption, which turns speech into captions as it plays and shows them in a small box. Google's Chromebook Help describes it as creating captions for audio and video played in the Chrome browser, so YouTube and other video you watch in a browser tab are covered. To turn it on (from Use captions on your Chromebook):

  1. Select the time at the bottom right of the screen.
  2. Select Settings, then Accessibility.
  3. Under Audio and captions, select Captions.
  4. Turn on Live Caption.

If that switch isn't there, Google says the feature isn't supported on your device yet. In the same menu you can change the caption font size, and you can drag the caption box to another part of the screen. Google's Chrome help also says that the audio and captions for Live Caption are processed locally and never leave the device, which is worth knowing if you're captioning something private (Manage captions and translations in Chrome). Menu names move around between ChromeOS releases, so if the steps don't match, search Settings for "captions".

Live Caption or a downloaded file?

They solve different problems, and on a Chromebook it's easy to end up using both.

Live Caption is for watching. It works on things that have no captions of their own, and you don't have to do anything per video once it's switched on. But the captions scroll past and are gone; you can't search them, quote them or keep them.

A downloaded file is for working with the text. A TXT transcript can go into Google Docs for notes, an SRT can go onto a video you're editing, and either one stays on the Chromebook after the video is gone. The catch is that FetchSubs can only download captions that already exist on YouTube. It doesn't listen to the audio, so for a video with no caption tracks, Live Caption is the tool that will give you something.

If you mostly want transcripts for study, the YouTube transcript page and the post on getting a transcript of a YouTube video cover that use in more detail.
